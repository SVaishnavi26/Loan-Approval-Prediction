About the Project

Underlying methodology, dataset schema, model comparison benchmarks, and feature analysis.

1. Project Overview & Methodology

The Loan Approval Prediction System demonstrates an end-to-end Machine Learning pipeline designed to assess loan applications as either Approved or Rejected.

The pipeline adheres to strict data science best practices: separating the 20% test partition before fitting preprocessors to prevent data leakage, handling data boundary anomalies without dropping records, and comparing four classification algorithms on identical hold-out test samples.

2. Feature Attributes

The system evaluates 11 input features derived from the 4,269-record dataset:

Feature Attribute Data Type Preprocessing Description
no_of_dependents Numerical StandardScaler Number of family dependents (0 to 5)
education Categorical OneHotEncoder Graduate vs. Not Graduate
self_employed Categorical OneHotEncoder Salaried Employee vs. Self-Employed
income_annum Numerical (₹) StandardScaler Gross annual income
loan_amount Numerical (₹) StandardScaler Requested loan amount
loan_term Numerical StandardScaler Repayment duration in years (2 to 20)
cibil_score Numerical StandardScaler Credit bureau score (300 to 900)
residential_assets_value Numerical (₹) Clipped ≥ 0 + Scaler Market value of residential property
commercial_assets_value Numerical (₹) StandardScaler Market value of commercial property
luxury_assets_value Numerical (₹) StandardScaler Value of luxury vehicles, jewelry, etc.
bank_asset_value Numerical (₹) StandardScaler Bank deposits and liquid savings
